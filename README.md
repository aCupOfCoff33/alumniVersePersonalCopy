# AlumniVerse 🌐  

AlumniVerse is a modern platform designed to connect alumni from educational institutions, empowering users to explore career opportunities, mentorship, and networking. Built with a clean interface and advanced filtering tools, it’s your go-to app for leveraging a thriving alumni network.

---

## 🚀 Features

### 🏠 Home Screen  

The home screen is the starting point for your journey. It greets you with:  
- A **dynamic gradient background** for a visually captivating design.  
- A prominent **"Start Networking"** button to jump straight into exploring alumni connections.  
- Highlights on the platform’s purpose and benefits.

### 🔍 Alumni Search and Filtering  

A powerful tool to explore alumni data with advanced filtering capabilities:  
- Filter by:  
  - **Companies**: Explore "Where They Work."  
  - **Majors**: Discover "What They Studied."  
  - **Locations**: Identify "What They Do."  
- Data is displayed in a **paginated grid layout** for clarity.  
- **Bar graphs** provide visual insights into alumni distribution.  

⚠️ **Privacy Note**: Alumni images are not displayed to ensure compliance with privacy standards.

### 🛠️ How It Works

1. **Explore Alumni**  
   - Browse a curated list of alumni profiles.  
   - Use filters to narrow results and gain tailored insights.  

2. **Data Scraping**  
   - Alumni data is collected using a custom **LinkedIn scraping tool**, ensuring detailed and accurate results while adhering to ethical guidelines.  

3. **Interactive Visualization**  
   - Bar graphs and grids display alumni information clearly and intuitively.

## 🧰 Technology Stack

### Frontend  
- **React.js**: For building dynamic and responsive user interfaces.  
- **Tailwind CSS**: Ensures a modern and polished design.  
- **Framer Motion**: Adds smooth animations and transitions.  

### Backend  
- **Custom LinkedIn Scraper**: For collecting verified alumni data from LinkedIn profiles.  
- **Python**: Handles filtering, summarizing, and preparing the alumni data.
